# HML-LiDAR RevA — macOS post-processing tools

This directory contains the macOS-side tools used by the HML-LiDAR RevA
post-acquisition workflow.

## Main workflow

| Stage | Program | Function |
|---|---|---|
| 0 | `0_mission_sync.sh` | Transfer raw ROS 2 acquisitions from the Raspberry Pi |
| 1 | `1_traiter_bag.command` | Run DLIO post-processing |
| 2 | `2_update_bag_EditeurTemporel_ZUPT.py` | Optional ZUPT-assisted temporal restart |
| 3 | `3_LancerPegar.command` / `Pegar.py` | Operator-guided multi-session registration |
| 4 | `4_LancerEditeur.command` / `EditeurReseau.py` | Revision of an existing Pegar network |
| 5 | `5-VisualisateurTopographiqueWithDensity.py` | Point-cloud inspection, density analysis and annotation |
| 6 | `6_ExtracteurTopographique.py` | VisualTopo-compatible `.tro` extraction |

## Additional visualization

`7-VisualisateurTRO.py` is an optional visualization and inspection utility
for the `.tro` files generated by the topographic extractor. It is not an
additional processing stage of the seven-stage RevA workflow.

## Supporting files

`serveur_alignement.py` provides the interactive alignment interface used by
Pegar.

`serveur_edition.py` provides the interactive interface used by the network
editor.

`Dockerfile` and `docker-compose.yml` define the RevA Docker/ROS 2
post-processing environment.

Additional conversion utilities retained in this directory are supporting
tools and are not part of the principal seven-stage processing sequence.

For the complete processing procedure, see:

`../../documentation/5.PostAcquisitionTreatmentPipeline.md`
