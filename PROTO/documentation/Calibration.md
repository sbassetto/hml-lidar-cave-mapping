# HML-LiDAR RevA — Calibration and Initialization

## English version

The HML-LiDAR RevA field workflow does not require a separate user calibration
of the Livox Mid-360 before each acquisition. The sensor is supplied with its
manufacturer calibration.

DLIO processing parameters are configured for the HML-LiDAR cave-mapping
workflow.

### Initial stationary period

Immediately after starting a recording, keep the helmet and LiDAR system
stationary for approximately **15 seconds**.

Do not deliberately move or rotate the helmet during this initialization
period.

The field protocol uses a longer stationary period than the minimum interval
implemented in the acquisition workflow in order to provide DLIO with a stable
initial sensor sequence before normal cave progression begins.

After this initial stationary period, the acquisition can proceed normally.

# Version française

# HML-LiDAR RevA — Calibration et initialisation

Le protocole de terrain HML-LiDAR RevA ne nécessite pas de calibration
utilisateur distincte du Livox Mid-360 avant chaque acquisition. Le capteur est
fourni avec sa calibration constructeur.

Les paramètres de traitement DLIO sont configurés pour le workflow de
cartographie souterraine HML-LiDAR.

### Période initiale d'immobilité

Immédiatement après le démarrage d'un enregistrement, maintenir le casque et
le système LiDAR immobiles pendant environ **15 secondes**.

Éviter de déplacer ou de faire pivoter volontairement le casque pendant cette
période d'initialisation.

Le protocole de terrain utilise une période d'immobilité plus longue que
l'intervalle minimal prévu dans le workflow d'acquisition afin de fournir à
DLIO une séquence initiale stable avant le début de la progression dans la
cavité.

Après cette période initiale d'immobilité, l'acquisition peut commencer
normalement.
